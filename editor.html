Optional local OBS audio

Auto connects to local OBS on port 4455 only when this page is served from localhost, 127.0.0.1 or [::1]. Authentication off: no password needed. Authentication on: enter the password using OBS Interact, separately for each source. Manual setup lets you change the local address and input names. Credentials stay in page memory, never in links/presets; refresh clears them. Configure before going live. Hosted pages and the embedded preview stay silent.

    Setup instructions
    1. Edit the scene on the left and watch the preview update.
    2. Copy all three sources at 1920×1080 — the starting, BRB and thanks links on the right.
    3. Add each copied link as a Browser Source in OBS at 1920×1080.
    4. Changes autosave to this browser but copied OBS links are snapshots, so copy again after editing.
    5. Browser storage isn't shared with OBS. Open this editor in the same browser to see your saved draft.
    Advanced settings
    Quality
    Use Low on older hardware, High only when the GPU has headroom. The preview uses the same quality as the copied links.
    Motion
    Reduce motion freezes 3D motion without changing your words or layout.
    Audio
    Auto connects only from a trusted localhost/loopback copy. OBS authentication is optional: if enabled, enter the password in each source using Interact. Credentials never enter links/presets and refresh clears them. Hosted copies stay silent. Use Ctrl+Alt+A (Command+Option+A on macOS) inside Interact to reopen setup. Existing legacy pages keep their local audio behavior.
    Secrets
    Don't put secrets in overlay text. Titles and subtitles appear on stream, so keep them free of passwords, keys and personal details.
    Storage
    Clear saved draft removes the autosaved copy from this browser only. It does not change links already copied into OBS.
